## What is Content

Content is the material the site presents, in whatever file it is stored:

- Papers and publications: `papers/`
- Documentation and wiki text: `docs/`, `wiki/`
- Product and catalog data and descriptions: `data/`, `products/`
- Site copy and book content: `src/content/`, `src/data/`
- Text, images, logos, diagrams, and media, including those in `assets/` and
  `public/`
- The names, logos, and branding of HF Laboratories and its products

## What is Code

Code is the source that builds and runs the site: Astro components, layouts,
pages logic, TypeScript and JavaScript, CSS, build configuration, the scripts in
`scripts/`, and the workflows in `.github/`.

In a file that mixes both, such as an HTML page, the markup and logic are Code
and the text and media it presents are Content.
